# **PROJET — GAMEPLAY**

## **Vers un véritable Football Manager politique**

### **Vision centrale**

Le jeu doit être conçu autour d’une ambition extrêmement précise :

**Créer l’équivalent d’un Football Manager politique.**

Pas un jeu narratif à choix multiples.

Pas un visual novel politique.

Pas un simple jeu de stratégie où l’on clique sur des politiques.

Pas un jeu où l’on choisit périodiquement entre trois options écrites par les développeurs.

Et même pas simplement un « Democracy 4 beaucoup plus gros ».

Le joueur doit avoir l’impression d’entrer dans **un monde politique vivant**, rempli d’acteurs autonomes, d’institutions, de groupes sociaux, de médias, de partis, de réseaux, d’organisations, de personnalités, de conflits et d’opportunités, puis d’essayer d’y construire progressivement sa propre trajectoire.

Le modèle mental doit être celui de Football Manager :

**Je ne joue pas contre un scénario. Je joue dans un écosystème.**

Football Manager obtient une grande partie de sa profondeur en faisant interagir une énorme quantité de données, d’attributs, d’acteurs et de décisions. Les développeurs décrivent notamment des managers IA qui évaluent le contexte et adaptent leur comportement, des joueurs dont les décisions dépendent de leurs attributs, ainsi qu’un système d’interactions dont les réactions tiennent compte de la personnalité, de la relation et du contexte. ([Football Manager](https://www.footballmanager.com/features/match-ai-and-animation?utm_source=chatgpt.com))

Le jeu politique doit reprendre cette philosophie, mais la pousser dans un domaine où les interactions possibles sont encore beaucoup plus nombreuses.

---

# **1\. Le fantasme de gameplay**

Le fantasme du joueur devrait être :

« Je commence presque personne. Je vais essayer de comprendre ce monde, de me créer une place, de rencontrer les bonnes personnes, de construire quelque chose, de saisir les opportunités, de prendre des risques et de voir jusqu’où cela peut m’emmener. »

Au début, le joueur ne contrôle presque rien.

Il possède :

* une identité ;  
* une situation professionnelle ;  
* un réseau limité ;  
* des compétences ;  
* des convictions ;  
* une réputation inexistante ou faible ;  
* des ressources limitées ;  
* quelques relations ;  
* éventuellement une ambition particulière.

Puis il agit.

Il rencontre des gens.

Il se fait connaître.

Il rejoint ou crée une organisation.

Il peut devenir militant, conseiller, journaliste, entrepreneur, responsable associatif, syndicaliste, élu local, collaborateur politique, chef de parti, ministre, opposant, candidat, président, etc.

Mais surtout :

**le jeu ne doit jamais lui dire à l’avance quel chemin il doit suivre.**

---

# **2\. Il ne doit pas y avoir une « classe politique »**

Le joueur ne doit pas nécessairement commencer comme politicien.

C’est fondamental.

Une des forces potentielles du jeu vient justement du fait que **le pouvoir politique n’est qu’une partie d’un système beaucoup plus large**.

Un joueur peut commencer comme :

* employé ;  
* professeur ;  
* avocat ;  
* journaliste ;  
* entrepreneur ;  
* étudiant ;  
* fonctionnaire ;  
* chercheur ;  
* militant ;  
* cadre associatif ;  
* syndicaliste ;  
* créateur de contenu ;  
* consultant ;  
* responsable local ;  
* etc.

Et à partir de là, différentes trajectoires deviennent possibles.

Un journaliste peut construire une réputation puis entrer en politique.

Un entrepreneur peut financer ou créer un mouvement.

Un universitaire peut devenir une référence intellectuelle.

Un militant peut construire une organisation.

Un fonctionnaire peut gravir progressivement les échelons.

Un inconnu peut devenir une personnalité publique.

Une personnalité publique peut créer un parti.

Un élu local peut progressivement construire un réseau national.

Un joueur peut même échouer à devenir un dirigeant mais devenir extrêmement influent autrement.

---

# **3\. L’objectif n’est pas « devenir président »**

Le jeu ne doit pas avoir un objectif unique.

Le joueur peut vouloir :

* obtenir un mandat ;  
* devenir ministre ;  
* prendre le contrôle d’un parti ;  
* créer un parti ;  
* influencer une politique publique ;  
* construire un mouvement ;  
* devenir une personnalité médiatique ;  
* devenir un puissant intermédiaire ;  
* contrôler une organisation ;  
* construire un réseau ;  
* défendre une idéologie ;  
* réformer les institutions ;  
* accumuler de l’argent et de l’influence ;  
* devenir chef d’État ;  
* transformer durablement le pays ;  
* ou simplement voir jusqu’où son personnage peut aller.

Le joueur peut même commencer sans savoir exactement ce qu’il veut.

Son objectif peut évoluer.

---

# **4\. Le monde doit être beaucoup plus grand que la politique électorale**

La politique électorale ne doit représenter qu’une couche du jeu.

Le véritable terrain de jeu est :

**la société entière.**

Il faut pouvoir agir à différentes échelles.

### **Échelle individuelle**

Une personne.

Un journaliste.

Un militant.

Un fonctionnaire.

Un conseiller.

Un entrepreneur.

Un universitaire.

Un influenceur.

Un élu.

Un policier.

Un responsable associatif.

Etc.

### **Échelle relationnelle**

Deux personnes peuvent :

* s’allier ;  
* se détester ;  
* se faire confiance ;  
* se trahir ;  
* se recommander ;  
* se concurrencer ;  
* négocier ;  
* s’influencer.

### **Échelle organisationnelle**

Partis, médias, entreprises, syndicats, associations, mouvements, administrations, cabinets, groupes d’intérêt, etc.

### **Échelle territoriale**

Quartier → commune → département → région → nation → international.

### **Échelle institutionnelle**

Municipalité → conseil régional → Parlement → gouvernement → justice → administration → institutions indépendantes, etc.

### **Échelle sociétale**

Classes sociales, groupes professionnels, générations, territoires, catégories économiques, groupes culturels, etc.

### **Échelle internationale**

Union européenne, États étrangers, organisations internationales, marchés, alliances, crises, conflits.

Le joueur doit pouvoir passer d’une échelle à l’autre.

# **5\. L’unité fondamentale du gameplay : l’interaction**

Le jeu ne doit pas être construit autour d’une liste de « missions ».

Il doit être construit autour d’interactions.

Une interaction signifie :

un acteur fait quelque chose à un autre acteur ou à un système, ce qui modifie potentiellement l’état du monde.

Exemples génériques :

* contacter quelqu’un ;  
* convaincre quelqu’un ;  
* recruter quelqu’un ;  
* proposer une alliance ;  
* demander un service ;  
* offrir un poste ;  
* lancer une campagne ;  
* publier une information ;  
* organiser une manifestation ;  
* créer une organisation ;  
* rejoindre une organisation ;  
* quitter une organisation ;  
* négocier ;  
* financer ;  
* soutenir ;  
* dénoncer ;  
* critiquer ;  
* défendre ;  
* enquêter ;  
* proposer une réforme ;  
* négocier une loi ;  
* influencer un groupe ;  
* lancer une campagne électorale ;  
* recruter des militants ;  
* obtenir des soutiens ;  
* créer une coalition ;  
* etc.

Mais chaque interaction doit avoir des conditions et des conséquences variables.

---

# **6\. Une infinité pratique de possibilités**

L’objectif n’est pas réellement de coder littéralement une infinité d’actions.

L’objectif est de créer suffisamment de **briques systémiques combinables** pour donner cette impression.

Par exemple :

100 types d’acteurs  
 × 100 types de relations  
 × 100 contextes  
 × 100 objectifs  
 × 100 ressources  
 × 100 actions  
 × 100 événements

produisent déjà une quantité gigantesque de situations.

La profondeur vient donc de la **combinatoire**, pas uniquement du nombre de boutons.

# **7\. Les personnages sont essentiels**

Il faut beaucoup de personnages.

Pas seulement quelques « personnages principaux ».

Le monde doit contenir une véritable population d’acteurs importants.

Un personnage peut avoir :

* âge ;  
* profession ;  
* situation sociale ;  
* richesse ;  
* compétences ;  
* réputation ;  
* idéologie ;  
* valeurs ;  
* ambitions ;  
* intérêts ;  
* personnalité ;  
* tempérament ;  
* réseaux ;  
* loyautés ;  
* rivalités ;  
* relations ;  
* connaissances ;  
* informations détenues ;  
* informations erronées ;  
* objectifs ;  
* peurs ;  
* tolérance au risque ;  
* historique ;  
* expériences ;  
* crédibilité ;  
* influence ;  
* ressources.

Et surtout :

**chaque personnage doit avoir sa propre vie.**

Il ne doit pas attendre que le joueur clique sur lui.

---

# **8\. Les personnages doivent pouvoir changer**

Un personnage n’est pas une fiche statique.

Il peut :

* changer d’emploi ;  
* changer d’organisation ;  
* changer de position politique ;  
* devenir plus ou moins populaire ;  
* perdre ou gagner de l’influence ;  
* créer des relations ;  
* rompre des relations ;  
* devenir ministre ;  
* être licencié ;  
* démissionner ;  
* être élu ;  
* perdre une élection ;  
* créer une entreprise ;  
* créer une association ;  
* rejoindre un parti ;  
* quitter un parti ;  
* devenir journaliste ;  
* devenir candidat ;  
* prendre sa retraite ;  
* mourir.

Le monde doit donc générer continuellement de nouveaux rapports de force.

---

# **9\. Les relations doivent être presque aussi importantes que les personnages**

Un personnage puissant ne doit pas seulement être « puissant ».

Il doit être puissant **parce qu’il possède certaines relations**.

Par exemple :

A connaît B.

B connaît C.

C contrôle une organisation.

D finance C.

E possède une audience médiatique.

Le joueur peut découvrir progressivement ces réseaux.

Il peut donc chercher non seulement :

« Qui est puissant ? »

mais :

« Qui connaît qui ? »

« Qui fait confiance à qui ? »

« Qui dépend de qui ? »

« Qui peut convaincre qui ? »

« Qui est réellement capable de bloquer cette décision ? »

Cela devient un véritable jeu de réseau.

---

# **10\. Le joueur doit pouvoir recruter des personnes**

À la manière du recrutement dans Football Manager, le joueur devrait pouvoir chercher des personnes en fonction de besoins.

Par exemple :

« J’ai besoin de quelqu’un capable de gérer mon organisation locale. »

Le système peut lui présenter :

* des candidats ;  
* leurs compétences ;  
* leurs expériences ;  
* leurs relations ;  
* leur réputation ;  
* leurs exigences ;  
* leurs loyautés ;  
* leurs risques.

Comme dans FM, le joueur ne devrait pas forcément tout savoir.

Il peut demander à ses collaborateurs de chercher.

Il peut obtenir plusieurs rapports.

Il peut comparer.

Il peut se tromper.

Football Manager utilise précisément des systèmes de recrutement où le joueur définit des besoins, puis ses équipes de recrutement recherchent et remontent des profils correspondants. ([Football Manager](https://www.footballmanager.com/features/recruitment-revamp?utm_source=chatgpt.com))

Le même principe peut devenir extrêmement puissant dans un jeu politique.

---

# **11\. Le joueur doit construire son « staff »**

C’est une idée majeure pour obtenir une vraie sensation Football Manager.

Le joueur ne doit pas tout faire lui-même.

Il doit progressivement constituer une équipe.

Par exemple :

* directeur de campagne ;  
* conseiller politique ;  
* conseiller communication ;  
* analyste ;  
* juriste ;  
* responsable terrain ;  
* responsable recrutement ;  
* responsable militant ;  
* conseiller économique ;  
* expert médias ;  
* attaché parlementaire ;  
* responsable sondages ;  
* etc.

Mais ces personnes doivent avoir :

* compétences ;  
* personnalités ;  
* objectifs ;  
* opinions ;  
* relations ;  
* rivalités.

Le staff peut donc devenir lui-même un système politique miniature.

---

# **12\. Le staff doit pouvoir être en désaccord**

Un bon conseiller ne doit pas simplement être une extension du joueur.

Il peut dire :

« Je pense que c’est une mauvaise idée. »

Un autre peut dire :

« Les données que nous avons montrent l’inverse. »

Un troisième peut avoir intérêt à pousser une stratégie.

Le joueur doit alors arbitrer.

Cela crée une couche supplémentaire d’information imparfaite.

---

# **13\. Le système de réunions**

Football Manager utilise les réunions et les rapports pour transformer une simulation extrêmement complexe en informations utilisables. Le système politique devrait reprendre cette logique. ([Football Manager](https://www.footballmanager.com/fr/features/objectifs-individuels-de-joueurs-et-logique-des-interactions?utm_source=chatgpt.com))

Le joueur pourrait recevoir :

### **Réunion stratégique**

« Où devons-nous concentrer nos efforts ? »

### **Réunion électorale**

« Quels territoires deviennent prioritaires ? »

### **Réunion médiatique**

« Pourquoi notre couverture médiatique change-t-elle ? »

### **Réunion organisationnelle**

« Pourquoi notre réseau militant perd-il de la puissance ? »

### **Réunion de crise**

« Que faisons-nous face à cet événement ? »

### **Réunion institutionnelle**

« Cette réforme rencontre telle opposition. »

### **Réunion économique**

« Nos ressources diminuent. »

Mais le joueur devrait pouvoir choisir :

* quels sujets suivre ;  
* quels sujets déléguer ;  
* quels rapports recevoir ;  
* quels sujets ignorer.

---

# **14\. L’inbox doit être centrale**

L’Inbox de Football Manager est particulièrement importante comme modèle.

Dans FM26, l’interface « Portal » cherche justement à réunir les événements importants et les informations pertinentes dans un point d’accès central, après que les développeurs ont constaté l’importance de l’Inbox dans l’usage du jeu. ([Football Manager](https://www.footballmanager.com/fm26/features/fm26s-reimagined-user-interface?utm_source=chatgpt.com))

Le jeu politique pourrait avoir une Inbox massive.

Exemples :

« Votre responsable local à Lille souhaite vous parler. »

« Un journaliste prépare un article sur votre mouvement. »

« Un député souhaite vous rencontrer. »

« Votre popularité vient de chuter dans trois régions. »

« Une association vient de soutenir votre proposition. »

« Votre adversaire vient de recruter une personnalité importante. »

« Un groupe industriel souhaite discuter avec votre équipe. »

« Une manifestation est en préparation. »

« Votre directeur de campagne recommande de modifier votre stratégie. »

« Une crise internationale vient de modifier l’opinion publique. »

« Votre ancien allié vient de rejoindre un mouvement concurrent. »

La majorité de ces événements ne devrait pas être écrite comme des scénarios fixes.

Ils devraient être générés par l’état du monde.

---

# **15\. Le joueur doit pouvoir cliquer profondément**

L’une des sensations importantes de Football Manager est :

« Tiens, c’est qui ce mec ? »

Puis :

clic.

Puis :

« Ah, il travaille avec lui. »

Puis :

clic.

Puis :

« Il était auparavant dans cette organisation. »

Puis :

clic.

Puis :

« Ah, donc cette décision vient probablement de là. »

Le jeu politique doit provoquer exactement cette sensation.

Le joueur doit pouvoir partir d’un événement et descendre progressivement dans les données.

Un article mène vers :

* l’auteur ;  
* le média ;  
* son propriétaire ;  
* son audience ;  
* ses relations ;  
* ses concurrents ;  
* les personnes citées ;  
* les organisations concernées.

Une décision politique mène vers :

* les responsables ;  
* les institutions ;  
* les groupes d’intérêt ;  
* les personnes favorables ;  
* les opposants ;  
* les conséquences territoriales.

Le monde doit être navigable comme un immense réseau.

---

# **16\. Le joueur doit pouvoir rechercher n’importe qui**

Il devrait exister un moteur de recherche interne.

Le joueur tape :

« économiste »

ou

« journalistes Bretagne »

ou

« militants écologistes »

ou

« personnes influentes dans le secteur agricole »

ou

« députés opposés à cette réforme »

ou

« personnes ayant travaillé dans telle organisation »

et le jeu renvoie des profils.

Cela transforme la base de données en véritable terrain de jeu.

---

# **17\. Le recrutement ne doit pas être limité à la politique**

Le joueur doit pouvoir recruter :

* politiciens ;  
* militants ;  
* communicants ;  
* journalistes ;  
* économistes ;  
* juristes ;  
* experts ;  
* organisateurs ;  
* entrepreneurs ;  
* chercheurs ;  
* influenceurs ;  
* responsables associatifs ;  
* etc.

Selon la trajectoire du joueur, certains profils deviennent plus importants que d’autres.

---

# **18\. Construire une organisation**

À un certain moment, le joueur peut décider :

« Je ne veux plus seulement agir individuellement. Je veux créer une organisation. »

Il peut alors construire :

* un mouvement ;  
* une association ;  
* un parti ;  
* un média ;  
* un think tank ;  
* une entreprise ;  
* un réseau militant ;  
* une organisation locale ;  
* etc.

La création d’une organisation doit ouvrir un nouveau niveau de gameplay.

---

# **19\. L’organisation devient elle-même un personnage**

Une organisation doit posséder :

* culture interne ;  
* réputation ;  
* ressources ;  
* membres ;  
* dirigeants ;  
* hiérarchie ;  
* idéologie ;  
* objectifs ;  
* implantation ;  
* réseaux ;  
* relations ;  
* conflits internes ;  
* procédures ;  
* communication ;  
* finances.

Elle peut évoluer indépendamment du joueur.

---

# **20\. Les luttes internes**

Une fois l’organisation suffisamment importante, les membres peuvent avoir leurs propres ambitions.

Cela permet :

* rivalités ;  
* factions ;  
* désaccords ;  
* coups internes ;  
* succession ;  
* contestation du dirigeant ;  
* scissions ;  
* alliances internes ;  
* promotions ;  
* exclusions.

Le joueur doit donc gérer son organisation comme un véritable système humain.

---

# **21\. Les factions**

Il ne doit pas être nécessaire d’avoir une seule idéologie par organisation.

Une organisation peut contenir plusieurs courants.

Par exemple :

* modérés ;  
* radicaux ;  
* pragmatiques ;  
* idéologues ;  
* technocrates ;  
* populistes ;  
* opportunistes ;  
* etc.

Ces factions peuvent :

* soutenir le joueur ;  
* négocier ;  
* s’opposer ;  
* quitter l’organisation ;  
* prendre le contrôle.

---

# **22\. Les partis politiques doivent être dynamiques**

Un parti n’est pas une entité figée.

Il peut :

* changer de dirigeant ;  
* modifier son programme ;  
* changer de coalition ;  
* perdre des membres ;  
* recruter ;  
* se diviser ;  
* fusionner ;  
* devenir marginal ;  
* devenir dominant.

*Victoria 3* constitue ici une référence intéressante : les partis peuvent émerger de coalitions de groupes d’intérêt et leur composition dépend de plusieurs facteurs, plutôt que d’être uniquement des blocs idéologiques statiques. ([Paradox Interactive](https://www.paradoxinteractive.com/games/victoria-3/news/dev-diary-46-political-parties?utm_source=chatgpt.com))

Le jeu politique devrait aller encore plus loin.

---

# **23\. Le joueur doit pouvoir infiltrer, influencer ou transformer des organisations**

Sans que cela soit limité à une mécanique « infiltration \= \+10 influence », le joueur peut tenter différentes formes d’action :

* rejoindre ;  
* convaincre ;  
* recruter ;  
* soutenir une faction ;  
* financer ;  
* concurrencer ;  
* créer une organisation rivale ;  
* négocier une alliance ;  
* proposer une fusion ;  
* attirer certains membres ;  
* etc.

Le résultat dépend du contexte.

---

# **24\. Le gameplay électoral**

Les élections doivent être une **conséquence de tout le système**, pas un mini-jeu isolé.

Une campagne implique :

* candidat ;  
* programme ;  
* réputation ;  
* organisation ;  
* ressources ;  
* médias ;  
* militants ;  
* financement ;  
* territoire ;  
* événements ;  
* adversaires ;  
* stratégie ;  
* communication ;  
* débats ;  
* mobilisation.

Le joueur doit décider où investir.

---

# **25\. La campagne électorale comme gestion de ressources**

Le joueur possède des ressources limitées.

Il peut investir :

* argent ;  
* temps ;  
* militants ;  
* communication ;  
* déplacements ;  
* événements ;  
* recrutement ;  
* sondages ;  
* organisation locale.

Il ne peut pas tout faire.

Il doit donc choisir.

---

# **26\. La campagne doit être locale**

Une des différences potentielles majeures avec un jeu politique classique serait la possibilité de descendre très bas dans l’échelle territoriale.

Le joueur pourrait voir :

* région ;  
* département ;  
* commune ;  
* circonscription ;  
* quartier, lorsque les données et la simulation le permettent.

Chaque territoire peut avoir :

* population différente ;  
* économie différente ;  
* préoccupations différentes ;  
* réseaux différents ;  
* personnalités locales ;  
* médias locaux ;  
* organisations locales.

Une stratégie nationale peut donc fonctionner très différemment selon les territoires.

---

# **27\. Les élections doivent créer des conséquences**

Gagner une élection ne doit pas être :

« Vous avez gagné → \+100 pouvoir. »

Gagner crée une nouvelle situation.

Il faut maintenant :

* gouverner ;  
* négocier ;  
* nommer ;  
* gérer l’administration ;  
* gérer les coalitions ;  
* faire passer des réformes ;  
* gérer l’opposition ;  
* gérer les médias ;  
* gérer les crises ;  
* gérer l’économie.

Le jeu change de dimension.

---

# **28\. Le gouvernement**

Une fois au pouvoir, le joueur doit pouvoir constituer son gouvernement.

Mais nommer quelqu’un n’est pas seulement choisir son niveau de compétence.

La personne possède :

* ses ambitions ;  
* ses relations ;  
* son courant ;  
* ses alliés ;  
* ses ennemis ;  
* sa réputation ;  
* ses intérêts.

Une nomination peut donc résoudre un problème et en créer un autre.

---

# **29\. Les institutions doivent résister**

Le joueur ne doit jamais simplement « contrôler l’État ».

Il doit interagir avec des institutions possédant leurs propres logiques.

Le Parlement.

La justice.

L’administration.

Les collectivités.

Les médias.

Les organisations sociales.

Les autorités indépendantes.

Etc.

Certaines coopèrent.

Certaines résistent.

Certaines négocient.

Certaines sont fragiles.

Certaines sont puissantes.

Cela crée un véritable jeu de pouvoir.

---

# **30\. Le gameplay de la vidéo « Comment devenir dictateur »**

La vidéo de départ doit être considérée comme **un catalogue minimal de possibilités**, pas comme la totalité du jeu.

Tout ce qu’elle décrit doit pouvoir apparaître dans la simulation lorsque les conditions nécessaires sont réunies.

Mais le jeu doit permettre beaucoup plus.

Par exemple, le joueur pourrait rencontrer des situations correspondant à :

* crise économique ;  
* polarisation ;  
* création d’un ennemi ;  
* bouc émissaire ;  
* propagande ;  
* répétition ;  
* modification des normes ;  
* contrôle narratif ;  
* exploitation des crises ;  
* affaiblissement progressif des institutions ;  
* concentration du pouvoir ;  
* neutralisation de contre-pouvoirs ;  
* opposition interne ;  
* mobilisation ;  
* répression ;  
* guerre ;  
* culte de la personnalité.

Mais aucune de ces mécaniques ne doit être une « route dictatoriale ».

Elles doivent être des **actions et phénomènes possibles dans un système politique général**.

---

* fiscalité ;  
* consommation ;  
* commerce ;  
* industrie ;

* énergie ;  
* etc.

### **Société**

* démographie ;  
* mobilité ;  
* éducation ;  
* urbanisation ;  
* inégalités ;  
* confiance ;  
* polarisation ;  
* mobilité sociale ;  
* etc.

### **Médias**

* presse ;  
* télévision ;  
* radio ;  
* réseaux sociaux ;  
* influenceurs ;  
* plateformes ;  
* journalistes ;  
* propriétaires ;  
* audiences ;  
* concurrence.

### **Institutions**

* Parlement ;  
* gouvernement ;  
* justice ;  
* administration ;  
* collectivités ;  
* autorités indépendantes ;  
* etc.

### **Organisations**

* partis ;  
* syndicats ;  
* associations ;  
* entreprises ;  
* ONG ;  
* think tanks ;  
* mouvements.

### **International**

* diplomatie ;  
* commerce ;  
* alliances ;  
* conflits ;  
* sanctions ;  
* crises ;  
* migrations ;  
* organisations internationales.

Chaque couche doit pouvoir interagir avec les autres.

---

# **32\. Les interactions transversales sont le véritable cœur**

L’objectif n’est pas d’avoir :

un système économique

* 	●	

un système médiatique

* 	●	

un système électoral.

Il faut que les trois systèmes **se parlent**.

Par exemple :

économie → chômage → mécontentement → média → perception → parti → campagne → vote → gouvernement → politique économique.

Mais aussi :

média → réputation d’un acteur → recrutement → parti → loi → économie → média.

Et :

événement international → économie → prix → opinion → gouvernement → élections → politique étrangère.

C’est cette circulation qui crée la profondeur.

---

# **33\. Les actions doivent avoir plusieurs types de conséquences**

Une action ne devrait presque jamais avoir une seule conséquence.

Elle peut modifier simultanément :

* popularité ;  
* réputation ;  
* confiance ;  
* relations ;  
* ressources ;  
* opinion ;  
* économie ;  
* cohésion ;  
* légitimité ;  
* mobilisation ;  
* stabilité ;  
* etc.

Et certaines conséquences peuvent être retardées.

---

# **34\. Les effets indirects**

Une caractéristique importante du jeu doit être l’existence d’effets indirects.

Le joueur peut faire quelque chose à A.

A réagit.

B observe A.

B change de comportement.

C réagit à B.

Une institution réagit à C.

Puis la population réagit à l’ensemble.

Le joueur ne contrôle pas cette chaîne.

Il doit la découvrir.

---

# **35\. Le joueur peut créer des stratégies émergentes**

Il ne faut pas que les développeurs aient besoin de prévoir toutes les stratégies.

Le joueur doit pouvoir inventer une stratégie que personne n’avait explicitement programmée.

Par exemple, combiner :

* une organisation ;  
* un réseau local ;  
* un média ;  
* quelques personnalités ;  
* une stratégie électorale ;  
* une réforme ;  
* une alliance.

Si les systèmes sont suffisamment généraux, cette combinaison peut produire un résultat inédit.

C’est là que le jeu devient réellement intéressant.

---

# **36\. Les « combos » systémiques**

Il peut exister des synergies.

Mais elles doivent être découvertes plutôt que présentées comme des recettes.

Par exemple :

une forte réputation \+ une bonne organisation \+ une crise \+ une personnalité crédible

peut produire une dynamique politique.

Mais le joueur ne doit pas voir :

« COMBO : crise \+ réputation \= succès ».

Il doit comprendre le mécanisme après l’avoir observé.

---

# **37\. La perception est aussi importante que la réalité**

Deux acteurs peuvent observer le même événement et en tirer des conclusions différentes.

Un gouvernement peut penser :

« La situation est sous contrôle. »

Une opposition :

« Le gouvernement est en train de perdre le contrôle. »

Un média :

« Il existe une crise. »

Un citoyen :

« Ma vie va mal. »

Le jeu doit donc distinguer :

### **état réel du monde**

et

### **perception de l’état du monde.**

C’est fondamental pour obtenir une vraie simulation politique.

---

# **38\. Les informations peuvent être fausses**

Les acteurs peuvent :

* se tromper ;  
* mentir ;  
* manipuler ;  
* mal interpréter ;  
* avoir des informations obsolètes ;  
* avoir des intérêts particuliers.

Le joueur doit donc parfois décider sans connaître la réalité.

---

# **39\. Les médias comme système de découverte**

Les médias ne doivent pas simplement servir à donner des événements au joueur.

Ils doivent être des acteurs.

Un média peut :

* enquêter ;  
* révéler ;  
* amplifier ;  
* minimiser ;  
* ignorer ;  
* commenter ;  
* influencer ;  
* subir des pressions ;  
* perdre sa crédibilité.

Le joueur doit donc aussi « jouer avec » l’écosystème informationnel.

---

# **40\. Les réseaux sociaux**

Les réseaux sociaux peuvent constituer une couche particulièrement dynamique.

On peut y observer :

* tendances ;  
* communautés ;  
* influenceurs ;  
* contenus ;  
* controverses ;  
* campagnes ;  
* rumeurs ;  
* mobilisations ;  
* réactions.

Mais il ne faut pas faire un simple compteur :

viralité \+10.

Il faut tenir compte :

* du réseau ;  
* de l’audience ;  
* de la crédibilité ;  
* du contenu ;  
* du contexte ;  
* de la concurrence ;  
* du moment.

---

# **41\. Les personnages doivent être générateurs de contenu**

Un événement intéressant peut être simplement :

« X vient de quitter le parti. »

Mais le joueur doit pouvoir cliquer sur X.

Puis voir :

pourquoi ?

Puis :

qui est X ?

Puis :

avec qui X est-il proche ?

Puis :

qui pourrait le recruter ?

Puis :

quelles conséquences cette rupture peut-elle avoir ?

Le contenu du jeu apparaît ainsi naturellement à partir de la base de données.

---

# **42\. Le jeu doit produire des histoires sans scénario**

C’est probablement la définition la plus importante du gameplay.

Une partie pourrait raconter :

un inconnu qui devient conseiller local, rencontre un journaliste, crée une association, recrute quelques personnes, devient conseiller municipal, fonde un mouvement, perd une élection, revient quelques années plus tard, récupère une faction d’un parti en crise, gagne une coalition, devient ministre, puis perd son poste à la suite d’un conflit interne.

Une autre :

un entrepreneur crée un média, gagne une influence énorme, soutient un mouvement politique, provoque une recomposition du paysage médiatique et finit par devenir lui-même une figure politique.

Une autre :

un militant reste marginal pendant dix ans avant qu’une crise sociale transforme soudainement son organisation en force nationale.

Aucune de ces histoires n’a besoin d’être écrite.

Elles doivent émerger.

---

# **43\. Le joueur doit pouvoir observer plutôt qu’agir**

C’est une composante importante de Football Manager.

Le plaisir ne vient pas uniquement de l’action.

Il vient aussi de :

regarder ce qui se passe.

Le joueur peut suivre :

* une personne ;  
* un parti ;  
* une ville ;  
* un média ;  
* une institution ;  
* une élection ;  
* une réforme ;  
* une crise ;  
* une tendance.

Il peut créer ses propres listes de suivi.

---

# **44\. Le joueur doit pouvoir « scouter » la société**

L’équivalent politique du scouting pourrait être énorme.

Le joueur peut demander à son équipe :

« Trouvez-moi les personnes influentes dans cette région. »

« Identifiez les journalistes qui parlent régulièrement de ce sujet. »

« Trouvez les organisations susceptibles de soutenir cette réforme. »

« Trouvez les territoires où notre implantation est faible. »

« Trouvez les personnes qui pourraient rejoindre notre mouvement. »

Le staff effectue alors le travail et revient avec des rapports.

---

# **45\. Le joueur doit pouvoir déléguer**

À partir d’un certain niveau, il devient impossible de tout gérer.

Il faut donc déléguer.

Par exemple :

* stratégie nationale ;  
* organisation locale ;  
* recrutement ;  
* communication ;  
* finances ;  
* relations institutionnelles ;  
* campagne.

Mais déléguer signifie aussi perdre du contrôle.

Un collaborateur peut prendre une mauvaise décision.

Il peut interpréter différemment les priorités du joueur.

Il peut poursuivre ses propres intérêts.

---

# **46\. La délégation doit devenir un vrai choix**

Le joueur doit constamment arbitrer :

« Est-ce que je m’occupe de ça moi-même ? »

ou :

« Est-ce que je laisse mon équipe gérer ? »

C’est exactement le genre de problème qui donne de la profondeur à un jeu de management.

---

# **47\. Le joueur doit progressivement changer de niveau de jeu**

Au début :

personnes.

Puis :

réseau.

Puis :

organisation.

Puis :

territoire.

Puis :

parti.

Puis :

gouvernement.

Puis :

État.

Mais même lorsqu’il atteint le sommet, il doit toujours pouvoir revenir au niveau individuel.

Le président peut encore recevoir une information concernant une personne qu’il a rencontrée dix ans auparavant.

Cette continuité donne une impression de monde vivant.

---

# **48\. Le joueur doit pouvoir perdre le contrôle**

Un des meilleurs aspects possibles du jeu serait que le joueur ne possède jamais une maîtrise absolue.

Son propre mouvement peut lui échapper.

Son parti peut lui échapper.

Ses alliés peuvent devenir ses adversaires.

Une personne qu’il a recrutée peut devenir extrêmement puissante.

Une réforme peut produire des effets qu’il n’avait pas anticipés.

Une organisation créée par le joueur peut survivre à sa propre carrière.

Le monde doit donc pouvoir lui résister.

---

# **49\. La succession**

Le jeu devrait idéalement permettre qu’une carrière ne s’arrête pas nécessairement avec le personnage.

Si le joueur devient très important, il peut avoir :

* successeurs ;  
* héritiers politiques ;  
* protégés ;  
* factions ;  
* collaborateurs.

Cela permet potentiellement une campagne très longue.

Mais même sans contrôler directement un successeur, le joueur pourrait simplement observer ce que devient le système qu’il a construit.

---

# **50\. Les crises personnelles**

Les personnages doivent également avoir leurs propres trajectoires.

Un collaborateur peut :

* tomber malade ;  
* partir ;  
* changer de métier ;  
* avoir un conflit ;  
* divorcer ;  
* déménager ;  
* gagner une élection ;  
* être impliqué dans un scandale ;  
* etc.

Il ne faut pas transformer le jeu en simulation de vie complète.

Mais suffisamment de continuité doit exister pour que les personnages aient l’impression d’exister indépendamment du joueur.

---

# **51\. Le scandale comme interaction systémique**

Un scandale ne doit pas être :

« Événement aléatoire : scandale. »

Il devrait pouvoir émerger de :

* comportement d’un personnage ;  
* enquête journalistique ;  
* information divulguée ;  
* conflit interne ;  
* erreur ;  
* adversaire ;  
* historique du personnage ;  
* contexte médiatique.

Puis produire :

* couverture médiatique ;  
* réactions politiques ;  
* réactions institutionnelles ;  
* perte de confiance ;  
* opportunités pour les adversaires ;  
* changements de coalition.

---

# **52\. Les lois et réformes**

Les réformes doivent être des systèmes à part entière.

Le joueur peut :

* proposer ;  
* négocier ;  
* modifier ;  
* temporiser ;  
* abandonner ;  
* prioriser.

Mais une réforme doit avoir :

* soutiens ;  
* opposants ;  
* coûts ;  
* effets ;  
* délais ;  
* conséquences politiques.

*Victoria 3* est intéressant à cet égard parce que ses changements de lois impliquent des groupes d’intérêt et des processus politiques plutôt qu’un simple bouton instantané. Les développeurs ont notamment fait évoluer le système pour éviter qu’une réforme ne soit réduite à un simple jet de probabilité. ([Paradox Interactive](https://www.paradoxinteractive.com/games/victoria-3/news/dev-diary-80-law-enactment-and-revolution-clock-in-13?utm_source=chatgpt.com))

Le jeu politique doit reprendre cette idée de **processus**, pas simplement de « bouton politique ».

---

# **53\. Les politiques publiques doivent modifier la société**

Une réforme doit avoir des conséquences matérielles.

Par exemple :

politique → coût budgétaire → services → emploi → opinion → groupes d’intérêt → élections.

Ainsi, la politique publique nourrit la politique.

---

# **54\. Les intérêts particuliers**

Des groupes peuvent avoir des intérêts particuliers.

Ils peuvent chercher à :

* obtenir une réforme ;  
* empêcher une réforme ;  
* obtenir des ressources ;  
* défendre une réglementation ;  
* changer une réglementation ;  
* gagner en influence.

Cela donne au joueur une multitude d’interlocuteurs.

---

# **55\. Les mouvements sociaux**

La population doit pouvoir se mobiliser.

Un mouvement peut :

* apparaître ;  
* grandir ;  
* se diviser ;  
* se radicaliser ;  
* se modérer ;  
* négocier ;  
* disparaître.

Il peut être local ou national.

Il peut être spontané ou organisé.

Il peut être récupéré par un parti.

Il peut aussi dépasser les organisations qui l’ont créé.

---

# **56\. Les manifestations et mobilisations ne doivent pas être des jauges**

Il ne faut pas :

« Mobilisation \= 72 »

et basta.

Il faut savoir :

* qui mobilise ;  
* pourquoi ;  
* où ;  
* comment ;  
* avec quelles ressources ;  
* contre qui ;  
* avec quelles alliances ;  
* quelle couverture médiatique ;  
* quelle réaction institutionnelle.

La jauge peut exister comme représentation synthétique, mais derrière elle doit y avoir un système.

---

# **57\. Le jeu doit avoir plusieurs niveaux de zoom**

### **Vue macro**

France entière.

### **Vue méso**

Régions, organisations, institutions.

### **Vue micro**

Personnes et relations.

Le joueur peut zoomer selon le problème qu’il essaie de comprendre.

---

# **58\. La carte n’est pas décorative**

La carte doit permettre de voir :

* implantation électorale ;  
* organisation ;  
* économie ;  
* mobilisation ;  
* influence ;  
* médias ;  
* événements ;  
* etc.

Le territoire doit avoir une vraie importance.

---

# **59\. Les territoires ont leurs propres écosystèmes**

Chaque territoire peut posséder :

* personnalités locales ;  
* organisations ;  
* médias ;  
* entreprises ;  
* problèmes ;  
* réseaux ;  
* cultures politiques ;  
* dynamiques économiques.

Ainsi, « conquérir la France » n’est pas simplement augmenter une jauge nationale.

Il faut construire progressivement des implantations.

---

# **60\. L’international comme autre terrain de jeu**

Le joueur doit pouvoir interagir avec :

* gouvernements étrangers ;  
* organisations internationales ;  
* entreprises étrangères ;  
* diplomates ;  
* médias étrangers ;  
* marchés internationaux.

Une décision intérieure peut modifier la diplomatie.

Une crise extérieure peut modifier la politique intérieure.

---

# **61\. La guerre et les crises internationales**

Elles doivent pouvoir avoir des conséquences :

* économiques ;  
* sociales ;  
* politiques ;  
* électorales ;  
* institutionnelles ;  
* médiatiques.

Le joueur ne contrôle pas nécessairement tous les événements internationaux.

Le monde extérieur existe lui aussi.

---

# **62\. Les autres pays doivent être autonomes**

Idéalement, la France n’est pas le seul pays simulé.

Même avec un niveau de détail inférieur à celui de la France, les autres États devraient avoir :

* gouvernements ;  
* intérêts ;  
* économies ;  
* alliances ;  
* crises ;  
* populations ;  
* politiques étrangères.

Cela permet d’éviter que le monde extérieur ressemble à une simple liste d’événements scriptés.

---

# **63\. La profondeur doit être asymétrique**

Tout n’a pas besoin d’être simulé avec la même précision.

La France peut être ultra détaillée.

Les pays étrangers peuvent être moins détaillés.

Les individus secondaires peuvent être agrégés.

Les personnages importants peuvent être simulés individuellement.

Cela permet de contrôler la complexité.

---

# **64\. La génération procédurale**

Une partie de la population et certains événements peuvent être générés procéduralement.

Mais la génération doit respecter des contraintes réalistes.

On ne veut pas :

« personnage random ».

On veut :

personnage cohérent avec son territoire, son métier, son milieu social, son histoire et ses relations.

---

# **65\. Les événements doivent être contextualisés**

Un même événement doit pouvoir avoir une forme différente selon le contexte.

Une manifestation dans une société stable n’a pas le même sens qu’une manifestation dans une société profondément polarisée.

Une déclaration d’un ministre pendant une croissance économique n’a pas nécessairement les mêmes conséquences pendant une récession.

Le moteur doit donc contextualiser.

---

# **66\. Le joueur doit pouvoir expérimenter**

Une partie devrait permettre :

« Et si je fais ça ? »

Le joueur peut tester une stratégie.

Puis recommencer une partie avec une autre.

Le jeu devient un laboratoire.

---

# **67\. Le joueur doit pouvoir comparer ses parties**

À la fin, il pourrait comparer :

* trajectoire économique ;  
* trajectoire politique ;  
* institutions ;  
* popularité ;  
* organisation ;  
* alliances ;  
* événements ;  
* durée au pouvoir ;  
* transformations sociales.

Pas sous forme de « score moral ».

Mais comme une analyse historique de sa partie.

---

# **68\. L’histoire générée**

À la fin d’une partie, le jeu devrait pouvoir produire une véritable chronologie :

2026 — création du mouvement.

2027 — première implantation locale.

2028 — alliance avec telle organisation.

2029 — crise économique.

2030 — première élection.

2031 — scission interne.

2032 — retour politique.

2034 — victoire électorale.

2036 — crise institutionnelle.

Etc.

Cette chronologie est le résumé de **ce que la simulation a réellement produit**.

---

# **69\. Le jeu doit donner envie de recommencer parce que le monde est différent**

La rejouabilité ne doit pas principalement venir de :

« Il y a 15 fins différentes. »

Elle doit venir de :

« Je ne sais pas ce qui va arriver si je recommence. »

Chaque partie peut avoir :

* nouveaux personnages importants ;  
* nouvelles alliances ;  
* nouvelles crises ;  
* nouveaux rapports de force ;  
* nouvelles opportunités ;  
* nouvelles trajectoires.

---

# **70\. L’objectif ultime : la liberté systémique**

Le joueur devrait régulièrement avoir des idées que le développeur n’avait pas explicitement prévues.

C’est le meilleur indicateur que le système fonctionne.

Le joueur doit pouvoir dire :

« Attends, si je fais X avec cette personne, puis Y avec cette organisation, peut-être que Z va se produire. »

Et tenter.

Si le moteur est bien conçu, quelque chose doit se produire.

Pas nécessairement ce qu’il imaginait.

Mais quelque chose de cohérent.

---

# **71\. Le gameplay doit ressembler à une enquête permanente**

Le joueur ne devrait pas simplement « commander ».

Il devrait aussi **comprendre**.

Qui est réellement influent ?

Pourquoi cette réforme bloque-t-elle ?

Pourquoi cette région nous rejette-t-elle ?

Pourquoi ce média nous attaque-t-il ?

Pourquoi cet allié change-t-il de position ?

Pourquoi cette organisation grandit-elle ?

Qui finance quoi ?

Quels sont les réseaux ?

Quel événement a déclenché ce changement ?

Cette dimension d’enquête est essentielle.

---

# **72\. L’information doit donc être une ressource**

Le joueur peut investir pour mieux connaître le monde.

Il peut :

* recruter des analystes ;  
* commander des sondages ;  
* demander des rapports ;  
* envoyer des personnes sur le terrain ;  
* consulter des archives ;  
* suivre des médias ;  
* observer les réseaux ;  
* recruter des experts.

Plus il grandit, plus il possède de moyens pour comprendre le système.

Mais il ne doit jamais obtenir une omniscience parfaite.

---

# **73\. Le joueur peut avoir plusieurs « écrans » comme dans FM**

L’interface peut comporter :

* Accueil / Portal ;  
* Inbox ;  
* Personnes ;  
* Organisations ;  
* Politique ;  
* Territoires ;  
* Médias ;  
* Population ;  
* Économie ;  
* Institutions ;  
* Diplomatie ;  
* Élections ;  
* Relations ;  
* Recherche ;  
* Rapports ;  
* Calendrier ;  
* Historique.

Les interfaces doivent rester connectées.

---

# **74\. Le principe « chaque écran mène à d’autres »**

Si je vois une baisse de popularité :

→ je clique.

Je vois les territoires concernés.

→ je clique.

Je vois les groupes concernés.

→ je clique.

Je vois leurs préoccupations.

→ je clique.

Je vois les médias qui ont récemment traité le sujet.

→ je clique.

Je vois les journalistes.

→ je clique.

Je vois leurs relations.

→ je clique.

Le joueur peut donc passer des heures à explorer le système.

---

# **75\. La profondeur vient de la navigabilité du monde**

Il ne faut donc pas seulement créer énormément de systèmes.

Il faut permettre au joueur de **les traverser**.

C’est une différence essentielle.

Une simulation peut être très complexe techniquement et pourtant donner l’impression d’être vide.

Ici, chaque donnée importante doit pouvoir devenir une porte vers autre chose.

---

# **76\. Le « Football Manager politique » en une boucle**

La boucle fondamentale devrait ressembler à :

**Observer → enquêter → comprendre → décider → agir → déléguer → attendre → recevoir des réactions → analyser → s’adapter.**

Puis :

**Observer à nouveau.**

C’est cette boucle qui doit être addictive intellectuellement, plutôt qu’une succession de récompenses artificielles.

---

# **77\. Le temps réel / pause**

Le jeu pourrait fonctionner comme un jeu de gestion en temps continu avec possibilité de :

* pause ;  
* vitesse x1 ;  
* vitesse x2 ;  
* vitesse x5 ;  
* éventuellement vitesse plus élevée.

Le joueur avance jusqu’à ce qu’un événement important apparaisse.

Cela permettrait de retrouver la sensation :

« Je laisse tourner… voyons ce qui se passe. »

Puis :

« Oh. »

Et le joueur met pause.

---

# **78\. Les événements interrompent le flux**

Lorsqu’une décision importante ou une crise apparaît :

PAUSE.

Le joueur examine.

Il peut :

* décider ;  
* déléguer ;  
* reporter ;  
* enquêter ;  
* ignorer.

Puis relancer la simulation.

---

# **79\. Le joueur doit avoir des priorités**

Comme dans un vrai jeu de management, le joueur ne peut pas tout gérer.

Il peut définir :

* priorités ;  
* objectifs ;  
* domaines surveillés ;  
* personnes suivies ;  
* territoires surveillés ;  
* indicateurs importants.

Le système adapte ensuite les rapports qu’il reçoit.

---

# **80\. Le jeu doit devenir progressivement plus complexe**

Au début :

peu de personnes, peu de ressources, peu d’informations.

Puis :

réseau.

Puis :

organisation.

Puis :

parti.

Puis :

institution.

Puis :

gouvernement.

Plus le joueur monte, plus le monde devient vaste.

Mais il ne doit pas devenir simplement plus compliqué.

Il doit changer de nature.

---

# **81\. Le paradoxe du pouvoir**

Plus le joueur obtient de pouvoir, plus il doit gérer de systèmes qu’il ne peut plus contrôler directement.

C’est une mécanique de gameplay fondamentale.

Au départ :

« Je décide. »

À la fin :

« Je donne une direction à un système gigantesque que je ne contrôle plus directement. »

C’est exactement ce qui peut donner au jeu son identité.

---

# **82\. Le joueur doit pouvoir créer son propre style de gouvernance**

Il n’existe pas de « build » officiel.

Le joueur peut développer :

* gestion technocratique ;  
* politique populaire ;  
* coalition ;  
* administration forte ;  
* pouvoir local ;  
* stratégie médiatique ;  
* mouvement militant ;  
* personnalisation du pouvoir ;  
* compromis permanent ;  
* confrontation permanente ;  
* etc.

Le système ne dit pas laquelle est meilleure.

Il simule leurs conséquences.

---

# **83\. Les styles peuvent évoluer**

Un joueur peut commencer modéré.

Puis devenir plus radical.

Ou commencer radical.

Puis devenir pragmatique.

Ou devenir plus institutionnel.

Ou perdre le contrôle de son propre mouvement.

Le style politique doit donc être une propriété dynamique du système.

---

# **84\. Le jeu doit permettre des trajectoires historiquement improbables mais systémiquement possibles**

Le but d’une simulation n’est pas de reproduire une seule histoire.

Elle doit permettre des histoires alternatives.

Mais elles doivent rester cohérentes avec les règles du monde.

Ainsi :

improbable ≠ impossible.

Une trajectoire exceptionnelle doit nécessiter des circonstances exceptionnelles.

---

# **85\. La philosophie finale du gameplay**

Le jeu doit produire une sensation très particulière :

**« Je peux essayer presque n’importe quoi, mais je ne contrôle jamais exactement ce que cela va provoquer. »**

Le joueur dispose d’une liberté immense.

Le monde dispose d’une inertie immense.

La partie devient la rencontre entre les deux.

---

# **86\. Ce qu’il faut absolument éviter**

Le projet ne doit surtout pas devenir :

### **Un arbre de dialogues**

« A / B / C ».

### **Un jeu de jauges**

« Influence \+5 ».

### **Un simulateur de président**

où tout se résume aux décisions du chef de l’État.

### **Une succession de crises aléatoires**

sans causalité.

### **Un jeu où les autres acteurs attendent**

que le joueur agisse.

### **Un jeu où tous les personnages sont décoratifs.**

### **Un jeu où toutes les stratégies ont une réponse prédéterminée.**

### **Un jeu où les événements sont plus importants que les systèmes.**

### **Un jeu où la recherche documentaire est uniquement décorative.**

### **Un jeu où l’IA invente les conséquences au fur et à mesure.**

Le gameplay doit toujours revenir au même principe :

**les systèmes produisent les événements.**

---

# **87\. Les jeux de référence**

Le projet devrait étudier plusieurs jeux, chacun pour une raison différente.

### **Football Manager**

Pour :

* densité de base de données ;  
* personnalités ;  
* attributs ;  
* recrutement ;  
* relations ;  
* staff ;  
* rapports ;  
* IA ;  
* interactions ;  
* délégation ;  
* information ;  
* interface ;  
* simulation continue.

FM constitue le modèle principal. Ses systèmes de recrutement, de rapports, d’interactions et d’IA montrent notamment comment une grande simulation peut être rendue manipulable par le joueur sans exposer toutes ses complexités internes. ([Football Manager](https://www.footballmanager.com/features/recruitment-revamp?utm_source=chatgpt.com))

### **Victoria 3**

Pour :

* population ;  
* groupes d’intérêt ;  
* partis ;  
* économie ;  
* lois ;  
* mouvements politiques ;  
* changements sociaux ;  
* rapports entre politique et économie.

Paradox présente explicitement *Victoria 3* comme une simulation de société dans laquelle les besoins et désirs des populations alimentent des groupes de pouvoir et où les changements politiques émergent progressivement. ([Paradox Interactive](https://www.paradoxinteractive.com/games/victoria-3/about?utm_source=chatgpt.com))

### **Crusader Kings III**

Pour :

* importance des individus ;  
* relations ;  
* familles ;  
* secrets ;  
* ambitions ;  
* intrigues ;  
* personnages autonomes ;  
* conséquences à long terme.

Paradox décrit notamment un monde rempli de personnages ayant leurs propres traits et choix, avec lesquels le joueur peut nouer des relations, les influencer, les trahir ou les utiliser. ([Paradox Interactive](https://www.paradoxinteractive.com/games/crusader-kings-iii/about?utm_source=chatgpt.com))

### **Democracy 4**

Pour :

* modélisation des politiques ;  
* effets systémiques ;  
* relations entre politiques et groupes de population ;  
* représentation des effets sous forme de données.

Sa documentation de modding montre notamment une architecture où les politiques possèdent des prérequis, coûts, délais et effets sur différents éléments de la simulation. ([Democracy 4](https://www.democracygame.com/mod_policies.html?utm_source=chatgpt.com))

### **Suzerain**

Pour :

* présentation narrative ;  
* décisions politiques ;  
* personnages ;  
* crises ;  
* conséquences narratives.

Mais le projet doit aller beaucoup plus loin que son approche scénarisée : *Suzerain* est explicitement présenté comme un jeu de drame politique fondé sur les choix, avec une histoire et plusieurs issues, alors que le projet ici doit faire émerger les histoires plutôt que les écrire à l’avance. ([Steam Store](https://store.steampowered.com/app/1207650?utm_source=chatgpt.com))

# **88\. La combinaison recherchée**

Le jeu idéal serait donc conceptuellement :

**Football Manager × Victoria 3 × Crusader Kings × simulation sociale × enquête politique**

avec une identité propre.

Football Manager apporte :

la profondeur de management.

Victoria apporte :

la société et les rapports de force structurels.

Crusader Kings apporte :

la puissance des personnages et des relations.

Democracy apporte :

les effets systémiques des politiques.

Suzerain apporte :

la lisibilité narrative des décisions.

Mais aucun de ces jeux ne doit être copié.

Ils servent à identifier les problèmes de game design que le projet doit résoudre.

---

# **89\. Le véritable « moteur de gameplay »**

Le moteur idéal pourrait être pensé comme une gigantesque boucle :

**POPULATION**

↓ influence

**GROUPES SOCIAUX**

↓ alimentent

**ORGANISATIONS**

↓ produisent

**ACTEURS**

↓ entretiennent

**RELATIONS**

↓ créent

**RAPPORTS DE FORCE**

↓ influencent

**DÉCISIONS**

↓ produisent

**ÉVÉNEMENTS**

↓ modifient

**POPULATION / ÉCONOMIE / INSTITUTIONS**

↓ recommencent.

Le joueur intervient dans cette boucle.

Mais il n’en est jamais le seul moteur.

---

# **90\. La définition finale du gameplay**

Le jeu doit donner au joueur la possibilité de commencer comme une personne presque inconnue dans une France simulée, puis d’interagir avec une société extrêmement dense composée de personnes, groupes, organisations, médias, institutions, territoires et États.

Il doit pouvoir rencontrer, convaincre, recruter, concurrencer, soutenir, quitter, créer, fusionner, négocier, déléguer, observer, enquêter et diriger.

Il doit pouvoir construire des réseaux et des organisations.

Il doit pouvoir participer à des élections ou les contourner.

Il doit pouvoir devenir influent sans être élu.

Il doit pouvoir créer un parti.

Il doit pouvoir reprendre un parti existant.

Il doit pouvoir construire un média ou utiliser l’écosystème médiatique.

Il doit pouvoir devenir ministre, parlementaire ou chef d’État.

Il doit pouvoir gouverner.

Il doit pouvoir réformer.

Il doit pouvoir échouer.

Il doit pouvoir perdre son organisation.

Il doit pouvoir être trahi.

Il doit pouvoir être dépassé par son propre mouvement.

Il doit pouvoir connaître une ascension fulgurante ou une progression extrêmement lente.

Il doit pouvoir suivre des centaines de personnes.

Il doit pouvoir découvrir des réseaux qu’il ne connaissait pas.

Il doit pouvoir faire des choses que les développeurs n’ont pas explicitement prévues, simplement parce que les systèmes permettent leur combinaison.

Et surtout :

**tout cela doit se dérouler dans un monde qui continue de vivre même lorsque le joueur ne fait rien.**

---

# **91\. Le critère absolu de réussite**

La question à poser à chaque mécanique est :

**« Est-ce que cette mécanique ajoute une possibilité d’interaction avec le monde, ou est-ce qu’elle ajoute seulement du contenu à consommer ? »**

Si elle ajoute seulement du contenu :

importance secondaire.

Si elle permet de créer de nouvelles interactions :

importance majeure.

La priorité doit donc être donnée aux systèmes génératifs.

Un nouveau type de personnage est intéressant s’il peut créer de nouvelles relations.

Une nouvelle institution est intéressante si elle modifie les possibilités d’action.

Un nouveau média est intéressant s’il peut influencer les acteurs.

Une nouvelle politique est intéressante si elle transforme plusieurs systèmes.

Un nouvel événement est intéressant s’il peut modifier durablement le monde.

---

# **92\. La formule ultime**

Le jeu doit viser cette sensation :

**« Le monde est tellement complexe que je ne peux pas prévoir son histoire. Mais il est suffisamment cohérent pour que je puisse essayer de la provoquer. »**

Et surtout :

**« Je ne veux pas connaître toutes les possibilités du jeu. Je veux découvrir qu’elles existent. »**

C’est cela qui permettrait réellement de dépasser l’idée d’un simple jeu politique à choix multiples.

Le but n’est pas de créer **beaucoup de contenu**.

Le but est de créer **beaucoup de possibilités produites par peu de règles fondamentales extrêmement interconnectées**.

Et c’est précisément là que l’idée de **Football Manager politique** devient pertinente.
