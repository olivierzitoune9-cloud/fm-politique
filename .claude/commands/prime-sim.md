# /prime-sim

> Démarrer une session avec le contexte complet du jeu, sans supposer l'état du monde.

## Mission

1. Lire dans l'ordre : `AGENTS.md`, `CLAUDE.md`, `docs/SPEC-v0-fm-politique.md`, `docs/suivi-attentes.md`, `HISTORY.md` (dernières entrées), `graphify-out/GRAPH_REPORT.md` si présent avec vérification de fraîcheur.
2. Résumer : ce qu'est le jeu en deux lignes, les dix principes en une phrase, l'état réel des phases, les trois attentes les plus urgentes, la dernière session.
3. Évoquer spontanément toute attente dont l'échéance approche ou qui bloque le sujet du jour.
4. Attendre le sujet de la session, sans coder.

## Règles

Français, tutoiement, pas de tirets longs, incohérences signalées calmement, jamais de supposition sur l'objectif du jour.
