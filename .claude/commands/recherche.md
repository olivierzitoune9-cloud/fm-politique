# /recherche

> Alimenter `docs/base-documentaire.md` sans jamais inventer. Un mécanisme, une fiche, des sources datées.

## Protocole

1. Rituel : journal du chercheur, SPEC section concernée, fiches voisines déjà écrites, graphe si code touché.
2. Chercher les primaires d'abord (articles, données officielles, textes de loi, rapports), les synthèses ensuite, jamais un résumé commercial comme autorité, jamais Wikipédia comme verdict final.
3. Remplir la fiche : variable, définition, causaux, conditions nécessaires, renforçateurs, atténuateurs, effets opposés, résultats empiriques, qualité des preuves, limites, sources datées, hypothèses de passage à la simulation.
4. Classer : établi, plausible, hypothèse de modélisation. Séparer donnée observée, paramètre estimé, règle scientifique, hypothèse de gameplay, paramètre technique.
5. Priorité immédiate : revérifier les références de la vidéo (Stenner, Tajfel, Hasher, Freedman et Fraser, Seligman, Centola, Bandura, Burger, Mueller, Klemperer) avec chiffres exacts avant tout codage.
6. Clôture : base mise à jour par écriture incrémentale, entrée journal, entrée HISTORY, graphe si besoin.

## Garde-fous

Aucune donnée inventée, incertitude déclarée, contradiction entre sources conservée et remontée à Aaron plutôt que lissée.
